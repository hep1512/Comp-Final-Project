Job Story Format

When [situation],
I want to [motivation / action],
So I can [expected outcome / value].

Example

When I am running late for class,
I want to quickly check my timetable on my phone,
So I can see which room I need to go to without asking others.


Employee:
When I need to help a customer with their order,
I want to be able to view information such as the products they have ordered, product codes, time of order and total price,
So I can settle any customer concerns and assure them as to when their order will be ready, and let them know about any stock issues.

When I need to stock up,
I want to have a useful tool to view inventory and identify stock issues,
So I can efficiently locate areas that need to be sorted out first and quickly address any issues.

Customer:
When I want to place an order,
I want to be able to view the prices of similar items that I am searching for,
So that I know I am getting a good deal and the products I want to buy

When I am browsing for a product,
I want to be able to view key information about it such as quantity, ingredients and allergens,
So that I know that the product is the best fit for me.
